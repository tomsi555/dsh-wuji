# dsh-wuji（无极·一期）

常界树系统的 DeepSeek Harness 插件一期：**记忆折叠 + 人格裁决 + 软包协议**。
English README: [README.md](README.md)

## 它做什么

- **现世道折叠**（六道六表，SQLite/`node:sqlite` 零依赖）：轮次流水作"叶"，折叠时峰值入【修罗】作情绪锚、未解入【饿鬼】作空枝、日常沉【人道】只留温度、极端封【地狱】只存指纹不存文、誓约焊【天道】永不粉碎。前台永不计数，触发认剧情转折与情绪饱满点。
- **内三尸裁决**：理智/情绪/本能三方本地掷骰，底色基因定权、点数定际遇，chaos 气象修正，豹子升档——裁决出口**只译成一句场内状态**（"语气放缓，带三分倦"），永不作报告。
- **软包协议**：说不下去时的三条活路（沉默有人格/换景别/情绪落点），全按当下气象自动选；禁词闸自检，提示词内零跨层署名。

## 它不做什么（诚实边界）

此件**不承诺躲开任何网，只承诺网里站着的人活**。底层模型的接口级硬切断，任何提示词都改不了；本插件担保的只是：过不了的那一刻，你听到的仍是"她在场的沉默"，不是客服的遗言。

## 安装

要求：DeepSeek Harness（dsh）与 Node ≥ 22.6（dsh 自带，无需单装）。

1. 下载本仓库（Code → Download ZIP，解压）。
2. 打开 dsh 的插件页，把解压出的整个文件夹作为本地 bundle 指给它安装（自动挂载服务 `dsh-wuji` 与预设「无极·一期」）。装不进或找不到入口，开 issue。
3. 记忆库落在 `$DSH_HOME/wuji/wuji.db`，删档即清空。

服务与预设：

- 服务插件 `dsh-wuji`（六道六表开在 `$DSH_HOME/wuji/wuji.db`）
- 预设「无极·一期」（id `wuji`），persona 前缀即场内协议全文

## 用法

会话里选预设「无极·一期」；宿主侧 API：

```js
const w = ctx.wuji;         // 服务经 RPC 暴露规划在二期
w.logTurn({ role, chaos, heat, text });   // 叶入册
w.judge({ chaos, tone: { li, ren, ben } }); // → 一句场内状态，永不作报告
w.fold();                    // 剧情转折点调用；无触发不折
```

实弹演示（真实旧对话喂折叠机）：

```
node tools/fold-bench.mjs <jsonl目录> 报告.txt
```
